# e-Comet — локальный MCP

Версия пакета: **2026.9.9**. Этот marketplace устанавливает только e-comet-local; отдельно установленный stage MCP сохраняется, production remote не добавляется.

MCP запускается напрямую, без тестового launcher и development-переменных. Обычные Codex и Claude manifests используют доверенные hooks для передачи подписанного разрешения browser_job; агент не переносит токен вручную.

Если клиент передаёт PLUGIN_DATA или CLAUDE_PLUGIN_DATA, результаты остаются в каталоге плагина. Если обе переменные отсутствуют, MCP использует постоянный каталог данных e-Comet текущего пользователя. Статус показывает выбранный backend. Ошибочные явно заданные пути не подменяются.

Нужно Node.js 22+, совместимое расширение e-Comet, вход в него через «Ключ расширения» и авторизованная вкладка Seller. Новая обычная сборка расширения поддерживает promotion packages и general analytics period/daily. Наличие инструмента проверяется вместе с capability расширения.

Ошибка открытия или чтения уже полученного XLSX не требует повторного создания отчёта.

Конфигурация принимает только официальный ID расширения. Проверка ещё не опубликованной unpacked-сборки требует изолированного development-запуска вне устанавливаемого пакета; этот marketplace не включает такой override.

После обновления плагина новая задача загружает его актуальную конфигурацию. [Изменения](CHANGELOG.md).
