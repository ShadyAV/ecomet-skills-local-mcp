# e-Comet — тестовый локальный MCP

Версия пакета: **2026.9.14**. Этот marketplace устанавливает только `e-comet-local`; отдельно установленный stage MCP сохраняется, production remote не добавляется.

Пакет работает с опубликованным расширением **e-Comet 1.5.7 или новее** из [Chrome Web Store](https://chromewebstore.google.com/detail/e-comet/apeallgchpgibifmbgefkhifidihmodh). При обычном запуске принимается только официальный ID `apeallgchpgibifmbgefkhifidihmodh`.

MCP запускается напрямую через Node.js 22+, без отдельного launcher и development-переменных. Доверенные Claude/Codex hooks передают подписанное разрешение `browser_job` без ручного переноса токена агентом. Нужны вход в расширение через «Ключ расширения» и авторизованная вкладка нужного маркетплейса.

Если клиент передаёт `PLUGIN_DATA` или `CLAUDE_PLUGIN_DATA`, результаты остаются в каталоге плагина. Иначе MCP использует постоянное хранилище текущего пользователя. Ошибочные явно заданные пути не подменяются.

Поддерживаются текущие WB-инструменты, пакеты promotion/analytics Ozon и защищённая отправка feedback. Ошибка чтения полученного XLSX не требует повторного создания отчёта.

Поколение bridge повышено до 7: новая сборка завершает работу прежнего primary и принимает его роль с актуальным кодом и официальным ID расширения. Двухчасовой host timeout оставляет запас для локальной передачи результата; подписанный часовой scope и ограничения операций не меняются.
