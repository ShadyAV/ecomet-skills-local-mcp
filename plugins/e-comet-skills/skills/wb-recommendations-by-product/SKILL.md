# Рекомендации WB по товару

## Workflow

1. Вызовите локальный MCP tool `wb_recommendations_by_product` один раз.
2. Передайте `articles` как объекты `{ "nmId": 791050753, "pages": N }`.
   Если `pages` не указан, tool загрузит всю обнаруженную полку, но не более 60 страниц.
3. Для первых N рекомендаций передайте `productLimitTotal`.
4. Для проверки присутствия конкретных товаров передайте `productNmIds`.
5. Используйте `articles[].pages[].products`; полные WB-ответы сохранены локально по `resultPath`.

Не открывайте вкладки, не управляйте DOM/CDP и не вызывайте `browser_job`. Локальный MCP сам общается с расширением e-Comet по localhost; данные не проходят через backend e-Comet.

Если расширение не подключено, вызовите `local_bridge_status` и попросите пользователя открыть Chrome с обновлённым расширением e-Comet и хотя бы одной авторизованной вкладкой `wildberries.ru`.

## Ответ пользователю

- Группируйте результат по `sourceNmId`.
- Используйте готовую сквозную позицию `globalPosition`; `position` — место на странице.
- Для списка показывайте артикул, название, бренд, `priceRub.product`, рейтинг и отзывы.
- Помечайте рекламу только при `promoted: true`.
- Если есть `incompleteReason` или статус `partial`, не утверждайте полноту полки.
- Рекомендации — снимок на момент запроса и могут меняться.
